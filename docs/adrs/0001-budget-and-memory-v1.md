# ADR-0001：V1 预算、记忆与本地验证基线

- 状态：Accepted for V1
- 日期：2026-09-19
- 范围：Stage 1 决策；Stage 2–4 实现约束
- 论文依据：p.3 `S005`，p.4 `S007`，p.5 `S009`，p.10 `S008`，p.10–16 `S011`

## 背景

论文给出了 RoCo 的角色、协作骨架、长期反思依据和主要实验参数，但没有完整定义记忆存储/检索、token/失败预算或可恢复记账。正文所述“每代最多 400 次 LLM API calls”与附录摘要中的“maximum 400 evaluations”不能安全视为同一指标。若只保留一个 `budget` 数字，无效输出、重试、缓存和多角色协作会使复现实验不可审计。

## 决策

### 1. 六类预算分别记录

每次运行独立维护以下单调账本，不做隐式换算：

| 字段 | 增加时机 | 单位/备注 |
|---|---|---|
| `llm_calls` | provider 接受一次请求时；失败、格式错、修复请求也计 | 次 |
| `tokens` | 按 provider 返回或 tokenizer 估算，至少拆为 input/output | token；估算值必须带 `estimated=true` |
| `generated_candidates` | 响应成功解析出一个新的候选方案时 | 个；不要求验证/评估成功 |
| `valid_evals` | evaluator 完成并返回可比较的有效目标值时 | 次；缓存命中另行记录，不重复伪增 |
| `cost` | provider/oracle 可归属费用发生时 | 币种与价格表版本必须记录；未知不得填 0 |
| `wall_time` | 运行开始到当前/结束的单调时钟耗时 | 秒；另可分角色和 evaluator 计时 |

每个实验配置必须显式设置至少一个硬停止条件。多个限制同时存在时，任何一个达到上限即不再发起新的消费动作；已经在途的工作如何结算由后续并行 ADR 规定。400 calls 和 400 evaluations 分别映射到不同 limit，报告中不得互换措辞。

### 2. V1 记忆采用 JSONL

长期记忆使用 append-only JSONL 事件流。每行至少包含 schema 版本、run/generation/round、role、父子候选引用、Critic 反馈引用、前后目标值、优化方向标准化的 `delta_g`、验证/评估状态、成功标志和时间戳。原始 LLM 对话、密钥和敏感输入默认不写入；若为调试保存，必须脱敏并留在未跟踪目录。

摘要是事件流的可重建派生物，携带来源事件 ID 与生成 prompt/model 版本；摘要不能覆盖原事件。写入应按代提交并支持崩溃后检测不完整记录。

### 3. 最近 K=5 的确定性检索

V1 对当前任务/角色作用域内可用事件按 `(generation, round, event_id)` 倒序，检索最近 `K=5` 条，并与角色累计摘要一同注入。上下文不足时先删除最旧事件的自然语言正文，但保留事件 ID、前后分数、`delta_g` 和状态。相似度、向量数据库、贡献度重排与跨任务检索不进入 V1。

### 4. 每个精英做三种角色变异

对进入 memory-guided mutation 的每个精英基座，固定发起 Explorer、Exploiter、Integrator 三种视角各一次变异。三者均遵循同一输出契约、分别记账并进入统一验证/评估与 Top-N 候选池。哪些个体算“精英”及精英数量仍必须由后续配置显式定义；本决策不伪造该论文缺失值。

### 5. 优先使用 Mock LLM

开发、CI、状态机验收和预算回归默认使用确定性的 Mock LLM。只有 Mock 路径能在相同 seed 下复现候选哈希、分数与六类账本后，才允许进行真实 provider 的小预算试运行。Mock 的结果只证明工程控制流，不作为论文性能复现证据。

## 后果

正面结果是预算歧义可见、无效输出不会被“成功评估数”掩盖、记忆可审计且本地测试不产生 API 成本。代价是 JSONL 不适合高并发/复杂相似度查询，六账本会增加 schema 和恢复测试工作，最近 K=5 也可能漏掉较旧但高价值经验。这些限制可在有实验证据后由新 ADR 替代，不能静默修改。

## 未在本 ADR 决定的事项

- 角色 token 的具体硬上限与上下文窗口。
- 无效代码最多重试几次及错误分类。
- 精英集合大小、EoH 各算子的候选 multiplicity 和总代数 `G`。
- 并行 reservation、在途任务结算、缓存命中与超时的完整语义。
- 真实模型、价格表、训练超时和论文数值复现协议。

这些事项登记在 `docs/gap_registry.md`，需在对应实现阶段前另行配置或形成 ADR。
